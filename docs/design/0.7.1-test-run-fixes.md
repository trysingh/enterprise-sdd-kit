# ekit 0.7.1 / kit 0.7.1 / golden fastapi-jinja 1.1.1: fixes from the first happy-path test run

Source: a vehicle-booking app built through the 0.7.0 happy-path lane. Requires `ekit >=0.7.0,<0.8` (unchanged).

1. **SMOKE-RUN** was green when `ekit run journeys` failed (e.g. exit 2: no venv / `uv.lock`). Now it fails with the exit
   code and the last 12 output lines; SMOKE-JOURNEYS-PASS still judges the report.
2. **Waves vs lane.** `ekit design approve --by` (happy-path lane, approved plan present) places the ACs of the features
   in the W0 slices into W0 (a slice is W0 unless it says `wave: <other>`), records `placed_from_design` (by, on, ACs)
   and a history entry in `.ekit/waves.yaml`. Every other unplaced AC is *proposed* for W1 in
   `docs/planning/waves.proposed.yaml`; a person confirms with `ekit wave approve --by`. `ekit wave validate` names these steps.
   brd/design/slice command texts say so in one line each.
3. **Migrations.** Golden ships `migrations/versions/0001_initial.py` (empty, frozen) and the convention: one revision per
   slice. `tests/conftest.py` uses a temp SQLite file (not `sqlite://`, a new DB per connection) and provides `db_schema`
   (`Base.metadata.create_all`) and `db_session`; the acceptance `app` fixture depends on `db_schema`.
4. **Journey steps.** Typed args `true`/`false`/numbers/`null` (quoted stays text); `the response does not contain "x"`,
   `the call fails with status N`, `the list is empty` / `the list "field" is empty`. Patterns do not shadow existing ones.
5. **Packages.** One package per `FEAT-` (`f<NNN>_<title>`) unless `design.yaml` gives features the same `package:`
   (snake_case). `ekit feature package FEAT-nn` prints it.
6. **DESIGN-PORTS-IMPLEMENTED.** A port with `adapter: in-process`, or one whose dependency function itself references
   the implementing class, is satisfied by a single class (still needs every declared method). The error now hints at this.
7. **`ekit init`** prints "Done with warnings", the failed step and the next step when `uv lock` failed; exit code 0.

Not changed: non-golden stacks, the classic lane, `reports/*.json` formats.
