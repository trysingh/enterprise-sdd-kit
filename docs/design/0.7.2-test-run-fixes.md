# ekit 0.7.2 / kit 0.7.2 / golden fastapi-jinja 1.1.2: fixes from the Haiku test run

Requires `ekit >=0.7.0,<0.8` (unchanged).

1. **Vacuous negative steps.** `the response contains "..."` and `the response does not contain "..."` resolve `{name}` (anywhere in
   the text) from values remembered in the scenario, like `contains the remembered`. An unknown `{name}`, or a `<name>` left
   unexpanded (HTML tags such as `<h1>` are exempt), raises the scenario-state error (broken glue, not a red). Patterns unchanged.
2. **`ekit init`.** Creates a missing target directory. Not in a git repo: `git init` + one commit `chore: ekit init`
   (no git, or no identity: a message with the command). Already in a repo: nothing is committed; the command is printed.
3. **Gates before design approval.** Happy-path lane, W0 empty and no design approval: one info line (waves are placed by
   `ekit design approve`) instead of "approved wave plan is no longer valid".
4. **DESIGN-DECISIONS.** The ADR cited by an accepted decision must contain the decision id or title (case-insensitive,
   whole words). `ekit adr new "Title" --decision D1` writes `**Decision**: D1 (title)` into the ADR; D1 must exist in design.yaml.

Not changed: classic lane, non-golden stacks, report formats.
